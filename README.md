# UCompensar Espacios · Mockup funcional

Prototipo académico (HTML + CSS + JavaScript, sin dependencias) del sistema de consulta y reserva de espacios.
Fundación Universitaria Compensar · Ingeniería de Software · Gestión de Proyectos · Actividad 6.

Integrantes: Fabio Andrés Narváez Díaz y Juan Diego Rey del Río.

## Cómo ejecutarlo
Abre `index.html` en el navegador. No requiere instalación ni servidor.

## Qué simula
- RF-01 Catálogo de espacios
- RF-02 Consulta de disponibilidad por fecha
- RF-03 Solicitud de reserva
- RF-04 Aprobación o rechazo (solo rol Gestor)
- RF-05 Historial de cambios de estado
- RF-06 Bloqueo de reservas aprobadas superpuestas (franjas contiguas permitidas)
- RF-07 / RNF-01 Roles y permisos

## Alcance
Datos sintéticos, en memoria. No hay base de datos, backend, notificaciones ni integración con el portal institucional.
